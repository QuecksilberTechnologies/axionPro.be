## Scenario and prerequisites

The scenario covers Policy Type, Policy Definition and Policy Assignment through
the shared durable pipeline. It requires a tenant token, matching leaf-module
Import/View permissions, active category/rule masters, and a running worker.
Assignment also requires a Published policy version and tenant employee code.
Sanitized inputs and the exact API sequence are in
`docs/UIdeveloperDoc/TENANT_POLICY_API.md`.

## Expected sequence

1. Download the target template.
2. Upload CSV/XLSX to preview; invalid rows block confirmation.
3. Confirm a valid Draft job; the worker rechecks permission and row data.
4. Poll until terminal, then download and reconcile the row report.
5. Cancel while Draft/Queued, or request cancellation while Running.
