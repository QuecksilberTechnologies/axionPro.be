## Superseded failure and root cause

The first deployed preview returned 500 because the target DB still enforced the
older bulk-master range. An earlier temporary verifier accidentally selected a
commented localhost connection entry; that successful check was local and was
not deployment evidence. The verifier was pinned to Production configuration,
the target migrations were applied, and the same authenticated scenario then
completed and reconciled.
