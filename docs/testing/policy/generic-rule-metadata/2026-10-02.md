## Implementation

- Added `PolicyCategoryRuleType`, `PolicyRuleSettingDefinition`, `PolicyRuleSettingOption` and

- Existing TenantPolicy lookups now include rule definitions.

- Resolve responses now include ordered stable-code rule definitions and configuration for
  every effective policy; this is compile-verified locally and awaits deployed API verification.
