## Investigation and changes

- Observed failure: deployed resend returned HTTP 500 and a generic message.
- Confirmed cause and evidence: Brevo rejected SMTP authentication with `525 Unauthorized IP address`. A MailKit authentication-only diagnostic confirmed that MailKit wraps the provider `SmtpCommandException` inside `MailKit.Security.AuthenticationException`.
- Confirmed code gaps: the Host resend handler selected the Tenant-first email method; the email service originally converted provider failures into `false`; and the first error-mapping change caught only the inner `SmtpCommandException`, allowing MailKit's outer authentication exception to reach the generic catch.
- Follow-up response evidence showed that non-authentication mail failures still returned `false`, which the resend handler converted into `INTERNAL_SERVER_ERROR`. Missing Host SMTP configuration, missing/inactive templates, SMTP protocol/connection failures, and unexpected mail-service failures now have distinct safe API error codes and HTTP 502 responses.
- A live SMTP smoke test using the deployment username and current deployment secret completed `EHLO`, STARTTLS, authentication (`235`), and provider submission successfully. Historical comparison confirmed that the previously working flow authenticated from `EmailConfig` deployment settings, while the new Host-default path authenticated with the database password. Host delivery now prefers `EmailConfig:SMTPUserName` and `EmailConfig:Secret`, falling back to the database values when deployment settings are absent; Host metadata, sender details, and templates remain database-driven.
- Brevo transactional logs contained only the accepted smoke messages and no application verification attempt. Code tracing found that Host delivery still queried and resolved Tenant SMTP before selecting the Host configuration. The Host path now skips Tenant SMTP query/decryption entirely, and the resend handler supplies Tenant display placeholders directly.
- Changed files and commit: application constants, resend handler, email service, Host regression tests and documentation; committed and pushed through `7ff24bfe1959e4f653ac2a16d22b4e47897b97f1`.
- The tests establish Host SMTP method selection and safe SMTP rejection mapping. They do not establish successful delivery from Render.

## Error reference and recovery

| Error / symptom | Confirmed meaning in this scenario | Required check or action |
| --- | --- | --- |
| `525 5.7.1 Unauthorized IP address` | Brevo SMTP IP blocking rejected the caller before mail submission. | Authorize the actual server outbound IP in Brevo, or disable SMTP IP blocking according to the deployment security decision. Retest SMTP authentication. |
| `SMTP_AUTHENTICATION_FAILED` | The SMTP provider rejected the selected username/secret, or wrapped a provider rejection during authentication. | Confirm the deployment `EmailConfig:SMTPUserName` and `EmailConfig:Secret`, remove accidental whitespace/line breaks, confirm that the SMTP key is active, then check IP authorization. Rotate any exposed key. |
| `SMTP_CONFIGURATION_UNAVAILABLE` | No usable active Host SMTP configuration could be resolved. | Verify the active `DefaultEmailConfig` row and deployment overrides. Host resend must use Host configuration and must not depend on Tenant SMTP. |
| `EMAIL_TEMPLATE_UNAVAILABLE` | The required active verification/welcome template was not found. | Verify the expected template code, active flag and Host scope in the email-template data. |
| `SMTP_CONNECTION_FAILED` | DNS, network, TLS or SMTP connection setup failed before successful authentication/submission. | Verify SMTP host, port, TLS mode and network reachability from the deployed service. |
| `EMAIL_DELIVERY_FAILED` | The mail service completed without a successful delivery result, but no more specific provider category was available. | Inspect the API log's underlying mail exception and Brevo transactional log. If Brevo has no matching event, the failure occurred before provider submission. |
| `INTERNAL_SERVER_ERROR` on resend | An unexpected exception escaped the mail-specific mapping. | Capture the server exception and correlation context. Do not diagnose it as a provider delivery failure unless Brevo contains a matching attempt. |
| Smoke email succeeds but Host resend fails and Brevo shows no resend event | SMTP transport is healthy; the application fails before SMTP submission. | Verify that the deployed build contains `7ff24bfe`, then inspect configuration/template resolution. This fix prevents Host resend from querying or decrypting Tenant SMTP first. |
